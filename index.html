1 What is this?นี่คืออะไร?

crypto_trading is a Python bot that automatically trades cryptocurrency on Binance. Every cycle it looks at the market, decides BUY / SELL / HOLD, and (optionally) places the order — then logs everything.

It has two interchangeable "brains" (engines):

⚙️ Rules engine (default)

Classic indicators: RSI + moving-average trend. No API key, no cost, fully deterministic and easy to test. Buys oversold, sells overbought.

🧠 Claude engine

Claude (Opus 4.8) reads the market each cycle and returns a decision with reasoning. More flexible, but needs an Anthropic API key and costs a little per cycle.

Whichever brain decides, the bot itself enforces the risk limits (stop-loss, take-profit, position size, daily cap) — risk is never left to the model.

crypto_trading คือบอทภาษา Python ที่เทรดคริปโตบน Binance โดยอัตโนมัติ ทุกๆ รอบมันจะดูตลาด ตัดสินใจ ซื้อ / ขาย / ถือ (BUY / SELL / HOLD) และ (ถ้าเปิดใช้) ส่งคำสั่งซื้อขาย แล้วบันทึกทุกอย่างไว้

มี “สมอง” (engine) ให้เลือก 2 แบบ:

⚙️ Rules engine (ค่าเริ่มต้น)

ใช้อินดิเคเตอร์คลาสสิก: RSI + แนวโน้มเส้นค่าเฉลี่ย (MA) ไม่ต้องใช้ API key ไม่มีค่าใช้จ่าย ผลลัพธ์แน่นอนและทดสอบง่าย ซื้อตอน oversold ขายตอน overbought

🧠 Claude engine

ให้ Claude (Opus 4.8) อ่านตลาดทุกรอบและตอบการตัดสินใจพร้อมเหตุผล ยืดหยุ่นกว่า แต่ต้องใช้ Anthropic API key และมีค่าใช้จ่ายเล็กน้อยต่อรอบ

ไม่ว่าจะใช้สมองแบบไหน ตัวบอทเองเป็นคนบังคับใช้ขีดจำกัดความเสี่ยง (stop-loss, take-profit, ขนาดไม้, จำกัดจำนวนเทรดต่อวัน) — ไม่ปล่อยให้โมเดลจัดการความเสี่ยงเอง

2 How it works (one cycle)หลักการทำงาน (1 รอบ)

📊 Data + Indicators→ 🛑 Risk exits (SL/TP)→ 🤔 Decide→ 🚧 Guardrails→ 💱 Execute→ 📓 Journal
  1. Data + Indicators — fetch candles, compute RSI / SMA20 / SMA50 / trend.
  2. Risk exits first — if holding and price hit stop-loss or take-profit, sell immediately (before asking the brain).
  3. Decide — the engine returns BUY / SELL / HOLD + a confidence 0–100 + a reason.
  4. Guardrails — block the trade if: already holding, daily cap hit, or confidence below threshold.
  5. Execute — place a market order on Binance (skipped while dry_run is on).
  6. Journal — append the full decision to trade_journal.jsonl; update bot_state.json.

Then it sleeps cycle_seconds (default 15 min) and repeats.

  1. ดึงข้อมูล + คำนวณอินดิเคเตอร์ — ดึงแท่งเทียน คำนวณ RSI / SMA20 / SMA50 / แนวโน้ม
  2. เช็คจุดออกก่อน — ถ้าถือเหรียญอยู่และราคาแตะ stop-loss หรือ take-profit ให้ขายทันที (ก่อนถามสมอง)
  3. ตัดสินใจ — engine ตอบ BUY / SELL / HOLD + ความมั่นใจ 0–100 + เหตุผล
  4. ด่านความปลอดภัย (Guardrails) — บล็อกการเทรดถ้า: ถือเหรียญอยู่แล้ว, ครบโควต้าเทรดต่อวัน, หรือความมั่นใจต่ำกว่าเกณฑ์
  5. ส่งคำสั่ง — ส่งคำสั่ง market บน Binance (ข้ามถ้าเปิด dry_run อยู่)
  6. บันทึก — เพิ่มการตัดสินใจลง trade_journal.jsonl และอัปเดต bot_state.json

จากนั้นพักตามค่า cycle_seconds (ค่าเริ่มต้น 15 นาที) แล้ววนซ้ำ

4 Setup & runติดตั้งและรัน

1. Get free Testnet keys (log in with GitHub → Generate HMAC_SHA256 Key).

2. Set up the environment and keys:

1. ขอ Testnet key ฟรี (ล็อกอินด้วย GitHub → Generate HMAC_SHA256 Key)

2. เตรียม environment และใส่ key:

cd crypto_trading
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

cp .env.example .env     # # then paste your TESTNET keys into .env# แล้ววาง Testnet key ลงใน .env
# BINANCE_TESTNET=true

3. Verify keys, then run the bot:

3. ตรวจสอบ key แล้วรันบอท:

python check_connection.py   # should show canTrade=True# ควรขึ้น canTrade=True
python trading_bot.py        # Ctrl-C to stop# กด Ctrl-C เพื่อหยุด

It starts double-safe: Testnet (fake funds) and dry_run (logs decisions, places no orders). Watch trade_journal.jsonl.

บอทเริ่มแบบ ปลอดภัยสองชั้น: Testnet (เงินปลอม) และ dry_run (บันทึกการตัดสินใจ แต่ไม่ส่งคำสั่งจริง) ดูผลได้ที่ trade_journal.jsonl

6 ⚠️ Everything you MUST know⚠️ สิ่งที่ต้องรู้

This can lose real money. Most automated trading bots are unprofitable. The risk limits here reduce damage — they do not guarantee profit.

  • Always start on Testnet with dry_run = True. Only go live after you trust the behaviour.
  • Go live carefully: set BINANCE_TESTNET=false, use live keys, start with a tiny trade_quote_amount.
  • Protect your keys: never commit .env, never share secrets, restrict the API key to your IP, and never enable withdrawals.
  • Not financial advice. You are responsible for every trade the bot makes.
  • Common errors: -2015 = wrong key / not testnet / IP not allowed; -1021 = computer clock out of sync.

บอทนี้ทำให้เสียเงินจริงได้ บอทเทรดอัตโนมัติส่วนใหญ่ขาดทุน ขีดจำกัดความเสี่ยงช่วยลดความเสียหาย แต่ ไม่ รับประกันกำไร

  • เริ่มที่ Testnet เสมอ โดยตั้ง dry_run = True ค่อยไปใช้เงินจริงเมื่อมั่นใจในพฤติกรรมของมัน
  • เปลี่ยนไปเงินจริงอย่างระวัง: ตั้ง BINANCE_TESTNET=false ใช้ key จริง และเริ่มด้วย trade_quote_amount น้อยๆ
  • ปกป้อง key: ห้าม commit .env, ห้ามแชร์ secret, จำกัด API key ให้เฉพาะ IP ของคุณ และ ห้ามเปิดสิทธิ์ถอนเงิน (withdrawals) เด็ดขาด
  • ไม่ใช่คำแนะนำการลงทุน คุณรับผิดชอบทุกการเทรดที่บอททำเอง
  • ข้อผิดพลาดที่พบบ่อย: -2015 = key ผิด / ไม่ใช่ testnet / IP ไม่ได้รับอนุญาต; -1021 = นาฬิกาเครื่องไม่ตรง

7 How to contributeวิธีร่วมพัฒนา

Contributions welcome! The workflow:

  1. Fork the repo and create a branch: git checkout -b feature/my-idea
  2. Make your change. Match the existing style — small, readable functions, clear comments, no new dependencies unless needed.
  3. Test on Testnet with dry_run = True before submitting. Never include real keys in a commit.
  4. Commit with a clear message, then open a Pull Request describing what and why.

Good first contributions 🎯

  • Backtester — replay a strategy over historical candles, report win-rate & P&L.
  • More indicators — MACD, Bollinger Bands, EMA crossovers in indicators.py.
  • Status dashboard — read trade_journal.jsonl and show position / P&L.
  • More pairs — let the bot trade several symbols at once.
  • Notifications — Telegram / Discord alert on each trade.
  • Docs & translations — improve this page or add another language.

Ground rules

  • Keep risk guardrails intact — never let a strategy bypass stop-loss / daily caps.
  • Default new features to the safe side (testnet, dry-run, small size).
  • One focused change per PR.

ยินดีรับการร่วมพัฒนา! ขั้นตอน:

  1. Fork repo แล้วสร้าง branch: git checkout -b feature/my-idea
  2. แก้ไขโค้ด ให้เข้ากับสไตล์เดิม — ฟังก์ชันสั้น อ่านง่าย คอมเมนต์ชัดเจน ไม่เพิ่ม dependency ถ้าไม่จำเป็น
  3. ทดสอบบน Testnet ด้วย dry_run = True ก่อนส่ง และห้ามใส่ key จริงใน commit
  4. Commit ด้วยข้อความที่ชัดเจน แล้วเปิด Pull Request อธิบายว่าแก้อะไรและทำไม

งานเริ่มต้นที่ดี 🎯

  • Backtester — ทดสอบกลยุทธ์กับข้อมูลย้อนหลัง รายงาน win-rate และกำไร/ขาดทุน
  • อินดิเคเตอร์เพิ่ม — MACD, Bollinger Bands, EMA crossover ใน indicators.py
  • หน้า Dashboard — อ่าน trade_journal.jsonl แล้วแสดงสถานะ / กำไรขาดทุน
  • รองรับหลายคู่เหรียญ — ให้บอทเทรดหลายเหรียญพร้อมกัน
  • การแจ้งเตือน — แจ้งเตือน Telegram / Discord ทุกครั้งที่เทรด
  • เอกสารและการแปล — ปรับปรุงหน้านี้หรือเพิ่มภาษาอื่น

กติกาพื้นฐาน

  • อย่าแตะระบบความปลอดภัย — ห้ามให้กลยุทธ์ข้าม stop-loss / โควต้าต่อวัน
  • ฟีเจอร์ใหม่ให้ตั้งค่าเริ่มต้นแบบ ปลอดภัย (testnet, dry-run, ไม้เล็ก)
  • หนึ่ง PR ต่อหนึ่งการเปลี่ยนแปลงที่ชัดเจน
